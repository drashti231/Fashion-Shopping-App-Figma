## ✨ About The Project

**Vogue** is a modern fashion shopping mobile app UI/UX concept designed in **Figma**.

The design focuses on creating a clean, stylish and personalized shopping experience where users can discover fashion products, browse categories and add products to their cart.

The interface uses a minimal black-and-white visual style combined with high-quality fashion imagery.

### 🖤 01. Onboarding

- Fashion hero image

- Minimal navigation
- Bottom navigation bar

---

### 👗 02. Home / Personalized Trends

The home screen provides a personalized fashion discovery experience.

**Features:**

- 👋 Personalized greeting
- 🔔 Notification button
- ✨ "Tailored Trends" section
- 🔎 Search bar
- 👩 Women's category
- 👨 Men's category
- 🧒 Kids category
- 🛍️ Fashion product cards
- ⭐ Product ratings
- 🛒 Add to Cart buttons

### 🛍️ 03. Product Listing

A clean product grid for browsing fashion items.

**Product examples:**

- Red Cherry Top
- Yellow Jump Suit
